# Cloudflare Database & Storage Setup Instructions\n\n## Prerequisites\n1. Install Wrangler CLI: `npm install -g wrangler`\n2. Login to Cloudflare: `wrangler login`\n\n## Step 1: Create Resources\n\n### Create D1 Database\n```bash\nwrangler d1 create church-content-db\n```\n**Copy the database ID from the output!**\n\n### Create R2 Bucket\n```bash\nwrangler r2 bucket create church-photos-bucket\n```\n\n## Step 2: Update Configuration\n\n1. **Update wrangler.toml**:\n   - Replace `your-database-id-here` with the actual database ID from Step 1\n\n2. **Update src/services/cloudflare.ts**:\n   - Replace `your-subdomain` with your actual Cloudflare subdomain\n   - Example: `https://church-portfolio-api.myname.workers.dev`\n\n## Step 3: Setup Database\n\n```bash\nwrangler d1 execute church-content-db --file=./schema.sql\n```\n\n## Step 4: Deploy Worker\n\n```bash\nwrangler deploy\n```\n\n## Step 5: Configure R2 Custom Domain (Optional)\n\n1. Go to Cloudflare Dashboard → R2 → church-photos-bucket\n2. Connect custom domain for public photo access\n3. Update photo URLs in worker.js\n\n## Step 6: Test the Setup\n\n1. Open your deployed worker URL\n2. Test endpoints:\n   - `GET /api/content` - Should return empty array\n   - `GET /api/photos` - Should return empty array\n\n## Environment Variables (if needed)\n\n```bash\nwrangler secret put API_KEY\nwrangler secret put ADMIN_PASSWORD\n```\n\n## Frontend Integration\n\n1. Update `API_BASE_URL` in `src/services/cloudflare.ts`\n2. Add ContentManager to your admin page\n3. Test content creation and photo uploads\n\n## Database Schema\n\nThe setup creates these tables:\n- `content` - Church content (services, events, announcements)\n- `photos` - Photo metadata and organization\n- `events` - Church events and schedules\n\n## API Endpoints\n\n### Content\n- `GET /api/content?type=service` - Get content by type\n- `POST /api/content` - Create new content\n- `PUT /api/content/{id}` - Update content\n\n### Photos\n- `GET /api/photos?category=services` - Get photos by category\n- `POST /api/photos/upload` - Upload new photo\n\n### Events\n- `GET /api/events` - Get upcoming events\n- `POST /api/events` - Create new event\n\n## Troubleshooting\n\n1. **Database not found**: Check database ID in wrangler.toml\n2. **CORS errors**: Verify CORS_ORIGIN in wrangler.toml\n3. **Upload fails**: Check R2 bucket permissions\n4. **Worker not responding**: Check deployment logs with `wrangler tail`
