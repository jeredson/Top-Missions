# Digital Sanctuary - Church Portfolio

A modern, responsive church website built with React, TypeScript, and Tailwind CSS.

## ✨ Features

- Modern, responsive design
- Service information and schedules
- Leadership team profiles
- Youth and teen ministry pages
- Contact information and location
- Admin panel for content management
- Mobile-friendly interface

## 🛠️ Technologies Used

- **Frontend**: React 18, TypeScript
- **Styling**: Tailwind CSS, shadcn/ui components
- **Build Tool**: Vite
- **Routing**: React Router DOM
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 📦 Installation & Setup

1. Clone the repository:
```bash
git clone <your-repo-url>
cd digital-sanctuary-church
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:8080](http://localhost:8080) in your browser.

## 🚀 Deployment

### Deploy to Vercel (Recommended)

1. Push your code to GitHub
2. Connect your GitHub repository to [Vercel](https://vercel.com)
3. Vercel will automatically detect it's a Vite project and deploy it
4. Your site will be live at `https://your-project-name.vercel.app`

### Deploy to Netlify

1. Build the project: `npm run build`
2. Upload the `dist` folder to [Netlify](https://netlify.com)
3. Configure redirects for client-side routing

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint

## 🎨 Customization

- Update church information in `src/data/content.json`
- Replace images in `src/assets/` with your church photos
- Modify colors and styling in `tailwind.config.ts`
- Update contact information in the contact page
